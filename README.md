## 💻 Running Locally

### Step 1: Clone or Set Up Directory

Create a local folder (e.g., `aleena-intro`) and place `index.html` inside it.

### Step 2: Open in VS Code

```bash
code .

```

### Step 3: Launch

* **Option A**: Double-click `index.html` to open directly in any default browser.
* **Option B**: Right-click `index.html` in VS Code and select **Open with Live Server** (requires the Live Server extension).

* **GitHub Pages**: Push this repo to GitHub, go to **Settings > Pages**, set source to `main` branch root, and share the live URL.
